# EC11E15244G1 旋钮

固件已加入实体旋钮，不需要 PC Python 后台。电脑语音识别仍按原来的 KEY4 操作。

| 操作 | 默认作用 |
| --- | --- |
| 顺时针转一格 | 向下滚动一个滚轮单位 |
| 逆时针转一格 | 向上滚动一个滚轮单位 |
| 按下旋钮 | 发送一次 Enter，确认当前焦点中的操作 |
| 一直按住 | 不重复发送 Enter，松开后可再次确认 |

每个滚轮单位对应多少行由 Windows 的鼠标设置和目标程序决定，不是固定一行。
Enter 在文本编辑器里通常表示换行，在按钮或对话框里通常表示确认。

## 实际接线

| 编码器端子 | 网络 / GPIO | 说明 |
| --- | --- | --- |
| ENC1.A | ENC_A / GPIO11 | R8 上拉到 3V3，固件同时启用内部上拉 |
| ENC1.B | ENC_B / GPIO12 | R9 上拉到 3V3 |
| ENC1.C | GND | 旋转触点公共端 |
| ENC1.D | ENC_SW / GPIO13 | R10 上拉到 3V3，低电平按下 |
| ENC1.E | GND | 按压开关另一端 |

接线来源为项目的 2026-10-22 网表，使用 GPIO 编号而非模块焊盘号。
型号按 [Alps Alpine 官方 EC11E 系列资料](https://tech.alpsalpine.com/cms.media/product_catalog_ec_01_ec11e_en_611f078659.pdf)
的 30 卡点、15 脉冲配置，每两个合法相变计为一格，00 与 11 都计为卡点。

## 烧录后先重新配对

此次增加了媒体控制输入报告（Report ID 3）。键盘报告（ID 1）与鼠标滚轮报告（ID 2）保留，但 HID 描述与配置读回长度已变化。

1. 关闭正在占用 COM24 的串口监视器，烧录 `esp32-s3-usb-debug`。
2. 在 Windows 蓝牙设置删除原来的 `ibook Keyboard`，重新添加它。
3. 打开一个有滚动条的网页或文档，将其置于前台，测试旋转。
4. 在记事本输入文字，按下旋钮，应只换行一次；保持按住不应连续换行。
5. 再测试 KEY1/2/3 和 OLED，确认旋钮与原有功能同时可用。
6. 使用语音时重新启动 PC 语音后台，使其连接重新配对后的设备。

## 屏幕和串口

旋转时，品牌名右侧临时显示上三角 ▲ 或下三角 ▼；按压后显示回车折返箭头与“确定”。
约一秒后图标消失，ibook 始终保留。图标由像素线条绘制，不依赖特殊符号字库。
蓝牙状态、快捷键区和录音状态区继续显示，不会被旋钮提示覆盖。

USB 诊断版本输入 `s` 打印一次状态，输入 `d` 开启/关闭变化日志。
`[ENC]` 行显示 A/B/SW 原始电平、按压状态、有效卡点累计数、滚轮就绪状态和动作编号。
SW 中 0 表示物理按下；`pressed` 中 1 表示消抖后按下。累计卡点数不是旋钮绝对位置。

## 修改方向和参数

`include/encoder_config.h` 中：

- `REVERSE_DIRECTION`：实物方向相反时改成 `true`，重新编译烧录，不需要重新配对。
- `BUTTON_DEBOUNCE_MS`：按压消抖，默认 25 ms。
- `CONFIRM_PULSE_MS`：Enter 按下到松开的间隔，默认 30 ms。
- `SCROLL_INTERVAL_MS`：滚轮提交间隔，默认 15 ms，快速旋转会合并为相对滚动报告。
- `FEEDBACK_MS`：屏幕提示持续时间，默认 1000 ms。

## 实现与验证

`rotary_decoder.h` 解码合法的 Gray 状态变化，接点来回抖动相互抵消，两位同时跳变时丢弃不完整半步。
`rotary_encoder.cpp` 的中断只累计旋转，不在中断里发送 BLE、刷屏或打印日志。
主循环发送相对滚轮，转动积压最多 32 格；断线和重连时丢弃旧积压，开机/重连时已按住的开关需先松开。
本地发送失败的相对滚动不重放，避免页面稍后突然滚动；可继续旋转下一格。

按压通过 `ShortcutKeys::setConfirmPressed()` 合并到现有键盘报告，不会覆盖正按住的快捷键。
如同时按住 Ctrl 快捷键再按旋钮，Enter 也会带有当前 Ctrl 修饰位，等同于普通键盘同时按键。
默认只针对单主机；真实方向、快速旋转和 Windows 滚动效果仍需实物验证。

主机测试编译执行实际 C++ 解码、旋钮和快捷键代码，模拟 GPIO 中断，不发送任何真实电脑输入。

## 网页切换旋钮模式

烧录本次固件后，在 Windows 删除旧的 `ibook Keyboard` 并重新配对，再打开工作台、连接键盘，点击示意图最右侧的旋钮。

| 模式 | 顺时针 | 逆时针 | 按下 |
| --- | --- | --- | --- |
| 页面滚动（默认） | 向下滚动 | 向上滚动 | Enter 确定 |
| 电脑音量 | 增大系统音量 | 减小系统音量 | 静音 / 取消静音 |

选择后点击“保存旋钮模式”。配置保存在键盘中，重启后恢复，不依赖 PC 工作台持续运行。
保存前需松开所有按键及旋钮并结束录音或传输；旧版保存的快捷键会保留，升级后默认采用滚动模式。
音量变化通过标准 HID Consumer Control 的 0xE9/0xEA/0xE2 usage 发送。Report ID 3 为 16 位 usage，每次按下后在主循环释放。
按住旋钮不会重复静音；再次松开、按下才会再切换。切换模式和断线会丢弃旋转积压。
OLED 在音量操作时显示 VOL+ / VOL-，按压时显示“静音”命令提示；这不表示电脑当前是否静音，实际状态由电脑控制。
网页的配置回复兼容旧固件 53 字节，新固件增加末尾一字节旋钮模式（0 滚动、1 音量）；旧固件连接后会提示需要升级。
保存使用原配置事务，新增 STAGE_ROTARY=5，格式 `[version, 5, transaction, mode]`，与三个快捷键一起原子提交并回读确认。
