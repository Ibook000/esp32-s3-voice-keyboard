# Web 快捷键配置

页面由电脑本地服务提供，使用蓝牙读取和保存键盘配置。KEY1～KEY3 可自定义，KEY4 保持录音，旋钮保持滚动和 Enter 确定。

实体按键从左到右依次为 **KEY4（录音）、KEY1、KEY2、KEY3**，旋钮在最右侧，屏幕在左上方。网页示意采用相同排列；KEY1～KEY3 的编号和配置对应关系保持一致。

## 第一次使用

1. 保存并关闭编辑器中尚未保存的旧代码，烧录本次 `esp32-s3-usb-debug` 固件。
2. 在 Windows 蓝牙设置删除原来的 `ibook Keyboard`，重新添加。此次增加了配置特征，需要刷新 GATT 缓存。
3. 双击项目中的 `pc/start.cmd`，浏览器会打开 `http://127.0.0.1:8787`。
4. 点击“连接键盘”，选择你的设备，页面会读取键盘当前保存的配置。
5. 点击 KEY1、KEY2 或 KEY3，填写名称，再点击“录入”并按组合键；也可直接勾选 Ctrl / Shift / Alt / Win，再选择普通键。
6. 松开实体按键、旋钮，并结束录音或发送后，点击“保存到键盘”。看到“已保存到键盘”才表示持久化及读取校验完成。

之后只改快捷键无需再次烧录或重新配对。配置保存在 ESP32 的独立 NVS 命名空间中，断电后保留。
快捷键仍由硬件通过 HID 发送，关闭网页和本地配置服务后依然可用。语音识别已整合到同一工作台，配置和音频共用一条 BLE 连接。点击网页 KEY4 可启停语音、选择模型、控制自动输入和查看最近结果。

如果已有服务在运行，再次双击启动文件会打开同一个配置页。
关闭浏览器标签不会结束本地服务；可点击页面底部“退出服务”结束服务。

手动启动方式（项目根目录）：

```powershell
rtk proxy .venv/Scripts/python.exe pc/web_config.py --open
```

运行环境沿用项目 `.venv` 和 `pc/requirements.txt` 中的 Bleak；网页不需要 npm 安装或构建。
`pc/web/package.json` 仅用于开发时运行 JavaScript 测试。

## 界面操作

- 名称：最多两个常用汉字，或四个英文/数字字符。名称只影响显示，快捷键由修饰键和普通键决定。
- 快捷键：支持字母、数字、F1～F12、方向键、Enter、Tab 等普通键，加上 Ctrl / Shift / Alt / Win。
- 录入：只在点击录入后捕获页面中的组合键，Esc 取消；Esc 本身可用普通键下拉选项设置。
- 系统保留组合键可能不会交给浏览器，例如 Win+L。请直接使用修饰键和普通键选项。
- 常用预设会修改当前选中按键的草稿；“恢复默认”也只改草稿，不会立即写入键盘。
- “撤销修改”恢复最近读到或保存成功的三组设置。
- “重新读取”读取键盘现有设置；若有未保存修改，会先询问是否丢弃草稿。
- 断线、保存失败、键盘正忙时，页面保留草稿，不会显示保存成功。
- OLED 屏幕示意随名称和组合键更新，不是实体屏幕的实时视频。长组合键在实体 OLED 上可能简写，C/S/A/W 分别表示 Ctrl/Shift/Alt/Win。

## 常见问题

**提示没有配置接口**：当前固件较旧，或 Windows 仍缓存旧 GATT 服务。先升级固件，再删除旧配对并重新添加。

**已配对但列表为空**：检查键盘电源、电脑蓝牙和设备名；页面会先查询 Windows 已配对设备，未找到时再扫描广播。

**保存时提示键盘正忙**：松开所有实体按键和旋钮，结束当前录音和发送，再保存。

**名称不能保存**：使用常用汉字、英文字母、数字、空格、下划线或连字符；首尾不要留空格。

**网页打不开**：双击 `pc/start.cmd`，或手动运行命令；日志在 `pc/runtime/web-config.log`。
如 8787 端口被其他程序占用，可手动加 `--port 8788`，再访问对应端口。

## 开发位置

| 路径 | 作用 |
| --- | --- |
| `pc/web/index.html`、`style.css`、`app.js` | 键盘示意图、按键编辑、录入、连接和保存状态 |
| `pc/web/model.js` | 浏览器按键映射、草稿、名称校验 |
| `pc/web_config.py` | 本地 HTTP 服务、独立 asyncio 蓝牙线程、启动/退出 |
| `pc/keymap_client.py` | 查找键盘、BLE 连接、逐步写入、设备确认和回读校验 |
| `pc/keymap_protocol.py`、`include/keymap.h`、`src/keymap.cpp` | 配置协议与事务校验 |
| `src/keymap_ble.cpp` | 加密 GATT 配置特征与主循环命令队列 |
| `src/keymap_store.cpp` | NVS 持久化与启动恢复 |

本地 HTTP 只绑定 `127.0.0.1`；修改操作检查页面令牌、Host 和 Origin。静态文件按白名单提供，无外部 CDN 依赖。
BLE 配置读写要求加密连接。所有活动配置只在固件主循环中切换，OLED 通过完整配置副本刷新，避免跨任务读到修改一半的名称。

## 配置协议 v1

配置接口位于现有语音服务内，不改变语音命令或 HID 报告：

- 写入特征：`cba10004-7d2f-4a6b-9c11-18d5e0010001`，Write with response。
- 读取特征：`cba10005-7d2f-4a6b-9c11-18d5e0010001`，Read / Read Blob。
- 每条命令不超过 20 字节，可用于 ATT MTU 23。配置读取结果新固件为 54 字节（旧固件 53 字节），系统完成长属性读取。
- 命令头：版本、操作、非零事务 ID；BEGIN=1、STAGE=2、COMMIT=3、ABORT=4。
- STAGE 后接按键索引 0～2、修饰位、HID 普通键、UTF-8 名称字节数、名称。
- 三个槽位都通过校验后才能 COMMIT；本地持久化成功后才统一替换活动配置。相同配置不会重复写 Flash。
- 读取结果前 8 字节依次为版本、结果码、事务 ID、操作、索引、暂存位图、修订号低/高字节。
- 后接三个 15 字节记录：修饰位、普通键、名称字节数、12 字节补零名称。仅返回活动配置，不泄露暂存中的半成品。
- 结果码：0 成功、1 格式错误、2 事务冲突、3 不完整、4 键盘正忙、5 存储失败。
- 不活动 15 秒或连接不再安全时取消暂存；断开中的保存无法得到确认时，页面保留草稿，重连后可读取实际设置。

客户端每条命令后校验事务 ID、操作和索引，最后还比较完整回读配置，避免把 GATT 写请求完成误认为已经保存。

参考：[Bleak 客户端 API](https://bleak.readthedocs.io/en/latest/api/client.html)、[ESP32 Preferences](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/preferences.html)。

## 统一语音输入

点击网页 KEY4 打开语音配置，再启用语音，选择识别和自动输入，点击“应用语音设置”。等待“等待 KEY4”后用实体录音键操作。
本次 PC 整合不新增固件协议，已有支持 Web 配置的固件即可使用。快捷键配置和语音订阅共享连接，停用语音仅取消音频订阅。
`GET /api/status` 包含 `voice` 状态与最多 8 条识别结果；`POST /api/voice` 接收完整 `{enabled, transcribe, type_text, model}`，沿用相同的页面令牌与来源检查。
语音设置保存到电脑，开启后下次启动恢复；首次使用默认为停用。取消识别为文字会同时关闭自动输入。
退出整个工作台会暂停接收并禁止旧识别结果继续输入；已保存 WAV 和 TXT 保留。仅关闭页面标签不会退出后台。
日常只用 `pc/start.cmd`，状态和停止脚本分别为 `pc/status.cmd`、`pc/stop.cmd`。详细说明见 [PC 说明](../pc/README.md)。

## 旋钮配置

点击网页右侧旋钮，选择“页面滚动”或“电脑音量”，再保存到键盘。音量模式旋转调节音量，按压切换静音。
本次新增媒体 HID 报告，需烧录支持此功能的新固件并删除旧蓝牙配对重新添加一次；之后更换模式只需网页保存。
配置回复从 53 扩为 54 字节，末尾为旋钮模式；PC 仍兼容旧回复。新增 `STAGE_ROTARY=5`，同一事务提交并保存。
`POST /api/rotary` 请求 `{ "mode": "scroll" }` 或 `{ "mode": "volume" }`，保留设备当前三个快捷键配置，持久化成功且回读一致后才报告保存完成。

## 深度睡眠配置

页面顶部“深度睡眠”仅配置自动深睡，不提供独立熄屏计时。新增 `STAGE_SLEEP=6`，格式 `[version, 6, transaction, minutesLo, minutesHi]`，允许 0～120 分钟，默认 10；0 关闭。新回复为 56 字节，53/54 字节旧回复仍可读取。`POST /api/sleep` 接收 `{ "minutes": 10 }`，不改动设备当前快捷键或旋钮模式。见 [完整深睡说明](deep-sleep.md)。
