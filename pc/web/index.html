连接你的键盘

先在 Windows 蓝牙设置中配对 ibook Keyboard。

自动深度睡眠

没有独立熄屏计时。闲置到指定时间后，关闭屏幕并进入深睡，蓝牙会断开。

按 KEY1～KEY4 或按下旋钮唤醒。第一次按下只唤醒，全部松开并等待蓝牙重连后，再正常操作。旋转旋钮不唤醒深睡。

录音、音频传输、配置保存或按键未松开期间不会进入深睡。设置保存在键盘，重启后保留。

连接键盘后读取当前设置。

几步就能设置好

  1. 首次使用，先烧录支持网页配置的新版固件，再删除 Windows 旧配对并重新添加。
  2. 点击“连接键盘”，读取键盘当前配置。
  3. 选择 KEY1～KEY3，修改屏幕名称，录入或选择组合键。
  4. 松开实体按键并结束录音，点击“保存到键盘”。看到保存成功后，设置即已生效。

Win 等系统组合键可能无法被浏览器直接录入，请改用修饰键和普通键选项。点击网页 KEY4 打开语音配置；实体 KEY4 仍用于录音，旋钮用于滚动和确定。
